## 📝 Individual Internship Reflection

### **What I Learned:**
During my internship at Nexvia, working on the Real-Time Financial Fraud Detection Platform was a deeply enriching technical experience. 
* **End-to-End AI Integration:** I gained hands-on expertise in bridging high-performance machine learning models (XGBoost and Graph Neural Networks) with a responsive, real-time frontend interface (Streamlit) using lightweight asynchronous APIs (FastAPI).
* **Scalable Infrastructure:** I deepened my practical understanding of containerization and local Kubernetes orchestration, learning how enterprise-grade systems handle high-frequency requests under strict latency constraints (<50ms).
* **Engineering Best Practices:** I refined my approach to clean repository structuring, version control hygiene, and building fault-tolerant data pipelines.

### **What I Owned:**
* **Full-Stack System Architecture:** I took complete ownership of designing and implementing the end-to-end data flow—from the SOC Dark Command Center UI down to the backend prediction microservice.
* **Documentation & Presentation Deliverables:** I independently authored the core technical documentation, system architecture specifications, API schemas, and structured presentation slide decks.
* **Execution & Delivery:** This project pushed me to think like a software engineer, ensuring that every component—from model inference speed to dashboard interactivity—met professional production standards.
